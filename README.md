# Ratatorta Quest: the lost keke. Juego del equipo RatatortaEntertainment de la asignatura de Proyecto Programación Avanzada 2026-II 
### Integrantes: Adrian Álvarez, Edson Caqueo, Vicente Moreno, Joahn Salvatierra y Vicente Vargas.

### ¿Qué contiene el repositorio? 
El repositorio almacena el progreso y las actualizaciones desarrolladas a lo largo de la creación del juego.

### ¿De qué trata el juego?
Ratatorta Quest: The Lost Keke es un videojuego de plataformas en 2D. Los jugadores controlan a una rata que adquiere diversos poderes a medida que desbloquea los distintos mundos y supera a los enemigos del juego. El objetivo principal es encontrar el tan ansiado y glorioso "lost keke".

### ¿Cómo inicializar el proyecto?
Hay dos formas:

**Mediante Git**:
Se debe tener Git instalado. Se abre la terminal o CMD y se coloca el comando `git clone <url>` donde url hace referencia a la del repositorio. Luego, se va a la carpeta del proyecto con `cd ProyectoPA`, y se usa el comando `git branch` para verificar si se está parado en la rama test, en caso contrario, se hace `git switch test`. Se procede a abrir la carpeta raíz del proyecto en Unity.

**Mediante ZIP**:
En el repositorio, se hace clic en Code > Download ZIP, se procede a descomprimir el archivo y abrir la carpeta raíz del proyecto en Unity.
